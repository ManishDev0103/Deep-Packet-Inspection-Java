<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser→legacy rule POST | Rule type/value are user-controlled and cross to Spring controller arguments |
| JSP rendering→browser | Server model values and flash messages are rendered as HTML |
| Unknown route→404 view | Arbitrary path text must not become executable markup or bypass the approved back route |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-04 | Tampering | Legacy delete/add POST | low | mitigate | Preserve `<c:out>` escaping and the server-side switch/RuleManager validation; UI confirmation never replaces POST validation |
| T-03-05 | Information disclosure | 404 and flash pages | low | mitigate | Keep unknown-path text out of HTML; render only fixed copy and the `<c:out>`-escaped flash content |
| T-03-06 | Denial of service | Legacy report table/forms | low | mitigate | Preserve internal table scrolling and real-width CSS fixes; do not allow long names or rule values to widen the page |
| T-03-SC | Tampering | npm/pip/cargo installs | high | mitigate | Package legitimacy gate: no dependency or package-manager install is included in this plan |
</threat_model>
